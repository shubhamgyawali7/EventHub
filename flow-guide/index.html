02

The Relational Blueprint

MongoDB schemas are heavily optimized with cross-references and unique indexing for data integrity.

👤

User Model

  • Roles: enum [Student, Club, Admin]
  • Profile: name, email, district, bio, skills
  • Relation: club (Ref: RegisterClub)
🏢

RegisterClub

  • Identity: name, logo, district, category
  • Status: Pending | Approved | Rejected
  • Creator: createdBy (Ref: User)
📅

Event Model

  • Core: title, date, deadline, price
  • Logic: isPaid, participantCount
  • Links: organizer (Ref: RegisterClub)
✅

Registration

  • Unique: {event: 1, user: 1}
  • Finance: paymentInfo, paymentService
  • Status: Confirmed | Pending | Failed

04

Defense & Middleware Stack

A multi-layered approach to protecting system resources.

JWT Authentication

Stateless session management. Tokens are decoded in auth.js middleware and attached to req.user.

RBAC (Role Based Access)

Granular control via roleBasedAuth.js. Ensures Students cannot hit Admin or Club-only endpoints.

CORS & Security Headers

Strict origin validation (FRONTEND_URL) and payload limits (10mb JSON / 50mb URL-encoded).
